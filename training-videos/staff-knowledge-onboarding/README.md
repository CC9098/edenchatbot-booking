# Staff Knowledge Onboarding Remotion Video

This Remotion project renders a short Cantonese training video for part-time nurse/staff onboarding.

## Render

```bash
npm install
npm run still
npm run render
```

Main output:

```text
training-videos/staff-knowledge-onboarding/renders/staff-knowledge-onboarding.mp4
```

The video is designed to be shown before the level tests in:

```text
docs/training/staff-knowledge-onboarding-level-tests-2026-05-09.md
```
