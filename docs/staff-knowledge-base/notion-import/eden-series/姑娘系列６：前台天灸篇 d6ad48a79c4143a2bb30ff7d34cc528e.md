**天灸基本內容：**

$720 包四貼(正常價)

$680（早鳥優惠）

1.第一次一定要由醫師負責貼＋病人要另外比診金$100

2. 第二貼開始，病人可決定由醫師或姑娘貼；

－醫師會按 身體實際情況 去調整去貼（但要比診金）；

－姑娘只會 基本7貼（固定位置）

3. 如果對天灸有身體敏感不宜再貼而又購買了早鳥優惠，可換做其他服務（ 一定要先跟醫師講，由醫師去決定）

4. 2023年夏天好熱，天灸加多點 凡士林

5. 貼天灸前會簽同意書，簽的時候可問病人需要影張相嗎？（因為同意書之後會比診所收回，及上載至GOOGLE DRIVE：「天灸同意書」）

**天灸分單:**

如天灸病人需要分單，要 **事先向病人確認收據出示 「天灸」字眼是否可做到保險索償。**

如病人不清楚 可先向保險公司確認一下，然後再跟我們說。

如病人「天灸」不能claim保險，只可轉兩個選項： 「**中藥藥費**」或「**外用藥**」。
