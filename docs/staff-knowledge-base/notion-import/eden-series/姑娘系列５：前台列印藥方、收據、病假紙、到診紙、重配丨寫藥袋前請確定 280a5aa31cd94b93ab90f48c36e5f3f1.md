# 姑娘系列５：前台列印藥方、收據、病假紙、到診紙、重配丨寫藥袋前請確定:

Created: 2023年8月17日 下午6:44
Updated: 2023年12月6日 下午7:31

**藥方:**

- 藥丸克數與粒數是否正確，服用次數及服藥時間是否一致。例如: 早上/晚上飯後，但每日次數卻是1次。
- 把藥物給予病人前留意姓名和日期是否正確。
- 處需highlight 強調: 處方備註、醫囑、注意戒口和中西藥物、保健品至少相隔2小時。
- 留意處方備註(例如先服、後服、月經頭3天服) 需簡單寫在包裝藥袋上。
- 請告訴新症病人藥粉的服用方法 (可參考小藥袋背後有指引)
- 若系統A5格式未能完全列印到完整處方，可使用系統內的「A4格式」以A5 size白紙列印處方(字型會變小，但內容完整更重要)

**收據:**

- 一日食2次藥，要留意是否$90一劑，或留意上次「一日2次」的藥費價錢是否相同。
- 藥丸＋藥粉正常情況下都是$90一劑
- 可在print藥方前或是姑娘執藥期間，就check定價錢是否正確。
- 荃灣長者(65歲以上)免診金。
- 如有折扣需要check回過往折扣記錄，若沒有任何資料需要向處方醫師查詢並確認是否給予病人折扣(若果是，請mark在折扣備註欄。

**病假紙:**

- 病假紙必須當日看診日期開始計算
- 若病人資料，如身份證號碼未齊全，可主動問病人是否okay，若不okay則需提供補回所需資料。
- **需要找「醫師簽署」**

**到診紙:**

- 病人需提供當日的指定時間(上午/下午/時間點)
- 若病人資料未齊全，可問病人是否okay，若不則需提供補回所需資料
- **需要找「醫師簽署」**

以上文件需蓋上醫師印和公司圓印

---

**若果有print錯了的病假紙/到診紙:**

- 要用黑筆完整刪掉姓名及身份證號碼，並**立即撕碎**。
