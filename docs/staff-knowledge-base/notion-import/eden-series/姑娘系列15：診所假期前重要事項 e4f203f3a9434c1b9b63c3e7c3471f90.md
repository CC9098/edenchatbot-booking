# 姑娘系列15：診所假期前重要事項

Created: 2023年11月26日 下午9:48
Updated: 2023年12月6日 下午7:32

- 何時需要更改手機信息/ 把手機旁身帶到其他診所回覆？*

若果有診所在 *非恆常日子中休診*（包括公眾假期／醫師休假的日子），

前一天上班的姑娘在下班前須幫忙：

- **Ａ. 診所手機***

1. 把手機的自動回覆信息改為 *一致傳出*

2. 自動回覆內容頂部加增一句:

(例子1)「中環診所23-26/11休診，歡迎聯絡其他診所預約。」

(例子2)「中環診所23-26/11休診，歡迎使用預約系統預約。」

看情況考慮否帶走手機，在休診的日子在其他診所上班時回覆。

！！完成後，請務必用私人手機傳信息一次到診所手機，以 *確認是否真的已成功更新自動回覆內容*

- --------
- **B. 門口告示***

尢其在非公眾假期／恆常休診日子，建議都將貼相關「休診告示」，告之walkin 病人診所情況。

- -------
- **C. 診所電話飛線***

若果是個別診所休診，請在休診前一個工作天，飛線到其他診所。
