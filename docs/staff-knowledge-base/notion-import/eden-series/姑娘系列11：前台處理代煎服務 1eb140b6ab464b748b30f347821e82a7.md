# 姑娘系列11：前台處理代煎服務

Created: 2023年8月21日 下午6:12
Updated: 2023年12月6日 下午7:32

不主動提供代煎服務。診所主要提供中藥藥粉、藥丸服務。

若有病人需要代煎服務：

1) 先掛號

2) 醫師睇症+開藥

3) 待醫師出左藥後，前台要將處方給醫師手寫代煎gram數 及 簽名、蓋醫師印。

4) 問病人取 寄藥地址

5) 然後whatsapp  代煎公司 查詢費用 : whatsapp group名: 「1515 Eden 醫天圓診所飲片代煎（下單及報價群組）」 (約30-45mins會報價 )

Example:

醫天圓中醫診所:

上載手寫藥方(連醫師簽名+蓋章、診所蓋章)

醫天圓中醫診所:

「客人名稱：蘇生 97488030

地址：南灣，鴨脷洲海傍道8號，七座27樓C室」

醫天圓中醫診所:

「麻煩請先提供報價表　以便我們與客人收錢　謝謝❤️」

6) （新症）先收診金$100+(基本藥費) $120@劑 ， 病人會先走(不用給藥方)，同病人交帶一聲, 「**$120是基本收費, 若因藥材材料問題而代煎公司報價時有較高收費, 我們會連同運費 , 稍後再向病人以網上付款形式收費。**」。

（舊症）**若果是舊症病人／醫師熟客，可建議病人若有事可先離開診所，待代煎公司報價後，再以網上付款形式收費。**

7) 代煎公司會直接向明惠收錢
