# 姑娘系列10：前台寫藥袋注意事項

Created: 2023年8月21日 下午5:31
Updated: 2024年2月6日 下午5:49

**選擇藥袋大小：**

按藥方每包克數，每天數量去決定，藥袋過大或過小都會影響病人的觀感。

**寫藥袋的地方：**

藥袋需要在平滑的平面上寫，建議有幾張紙墊底。（不建議直接在藥機上寫，因為有少許凹凸位，令到字體寫出來會不美觀。）

**寫藥袋的筆：**

可觀察書寫時筆尖會否太利，界到藥袋，以及書寫時會否墨水過多，容易弄污藥袋。

**寫藥袋的速度及字體：**

即使配藥速度好急，但寫藥袋不可以急！

- 文字及數字都不可穿過底線
- 字體必須為大小適中
- 每隻字間距一致
- 字體清晰

以令人看得舒適的方向去寫。

**如寫錯字需修改：**

修改少部份可以用「改錯帶」。

但若果需要修改的部分是：

1. 病人姓名
2. 十分重要的資訊

請**直接拿「新的藥袋」再寫**，以便即使改錯帶不小心抹掉了，都不會令病人誤會。
