# Eden 系統說明書總目錄
## 最後更新：2026-02

呢個資料夾收錄六份說明書，全部用淺白人話寫，方便前線、管理層同系統 Owner 使用。

## 快速入口

| 文件 | 適合誰 | 重點 |
|------|--------|------|
| [01-管理者說明書](./01-管理者說明書.md) | 管理者、店長 | 日常營運、權限、排班假期 |
| [02-中醫師說明書](./02-中醫師說明書.md) | 醫師 | 體質評估、護理指引、覆診計劃 |
| [03-姑娘排單說明書](./03-姑娘排單說明書.md) | 前台姑娘 | 代病人落單、改期取消、常見情況 |
| [04-病人使用說明書](./04-病人使用說明書.md) | 病人 | 預約、改期、取消、AI 諮詢 |
| [05-開發者說明書](./05-開發者說明書.md) | 系統 Owner | 架構、環境變數、部署、排錯 |
| [06-AI-Chatbot-V2改良說明書](./06-AI-Chatbot-V2改良說明書.md) | 系統 Owner | V2 模式路由、知識庫、改良方法 |
| [姑娘內部知識庫](../docs/staff-knowledge-base/README.md) | 前台姑娘、管理層 | Google Doc 內容整理、SOP、話術、待補資料 |

## 建議閱讀方式
1. 管理者先睇管理者版，了解整體流程同風險位
2. 醫師睇中醫師版，按病人檔案流程操作
3. 姑娘睇排單版，跟標準話術同落單步驟
4. 病人版可直接發畀病人參考
5. 系統 Owner 先睇開發者版再睇 AI 改良版

## 快速定向

- **姑娘想知道點幫病人落單** → [03-姑娘排單說明書](./03-姑娘排單說明書.md)
